# API Documentation

Generated by AI-DLC Reverse Engineering against git `6c09efd` (Aileron 0.1.3), 2026-08-12.
Signatures and flags below were read from the implementation, not from `README.md` or `SPEC.md`.

## REST APIs

None. Aileron exposes no HTTP surface and makes no network calls at runtime. Its interfaces are a
Python API, a console script, and a JSON-RPC stdio proxy that speaks the Model Context Protocol
between an existing client and an existing server.

## Internal APIs

### Public package surface — `aileron/__init__.py`

`__all__` is exactly: `__version__`, `ChainLog`, `track`, `track_agent`, `PolicyBlocked`,
`load_rules`, `Baseline`, `verify`, `bundled_rules_dir`. All but `__version__` and
`bundled_rules_dir` resolve lazily through `__getattr__`; anything else raises `AttributeError`.

Deliberately **not** in the top-level surface, reachable only via submodule import: `Rule`,
`Decision`, `decide`, `matches`, `new_event`, `digest`, `event_hash`, `canonical_json`, `validate`,
`render_html`, `export_json`, `to_otel_spans`, `to_otlp_spans`, `run_proxy`, `generate_keypair`,
`sign_checkpoint`, `verify_checkpoint`, `check_against_checkpoints`.

### `aileron.events`

- `canonical_json(obj: Any) -> str` — `json.dumps(obj, sort_keys=True, separators=(",", ":"), ensure_ascii=True, allow_nan=False)`.
- `digest(obj: Any) -> str` — SHA-256 hex of `canonical_json(obj)`.
- `canonical(event: dict) -> str` — canonical JSON of the event minus `hash`.
- `event_hash(event: dict) -> str` — SHA-256 hex of `canonical(event)`.
- `new_event(type, session_id, agent_name, framework, **fields) -> dict` — seeds `id` (uuid4 hex),
  `ts` (RFC3339 UTC, ms, `Z`), `seq=0`, `status="ok"`, `latency_ms=None`, `meta={}`,
  `prev_hash=hash="0"*64`; derives `tool.arguments_digest` from `tool.arguments` and `result_digest`
  from `result` when absent; merges an `agent=` override onto `{name, framework, version}`.
- `validate(event: dict) -> list[str]` — returns schema errors, `[]` if valid. It checks presence,
  type, **and** value format: `id` against `[0-9a-f]{32}`, `ts` as parseable RFC3339, `seq >= 0`,
  `type` and `status` for enum membership, digests and both hashes against `^[0-9a-f]{64}$`, and the
  required sub-keys of `agent` and `policy`. What it does *not* do: reject unknown extra keys, or
  verify that `hash` is the correct hash of the event.
- Constants: `EVENT_TYPES = {"tool_call","llm_call","agent_start","agent_end","policy_decision","alert"}`,
  `STATUSES = {"ok","error","blocked"}`, `EVENT_KEYS` (15 keys).

### `aileron.chainlog`

- `class ChainLog(path: str, capture_content: bool = False)` — replays the file on construction to
  recover `_last_seq` / `_last_hash`.
  - `append(event: dict) -> dict` — works on a copy (the caller's dict is not mutated); assigns
    `seq = last + 1`, `prev_hash`, and `hash`; strips `tool.arguments` and `result` to `None` unless
    `capture_content`; writes one canonical line plus `\n`. Digests are never stripped.
  - `__iter__() -> Iterator[dict]` — lenient: skips undecodable, unparseable, and non-dict lines so a
    damaged journal can still be read.
  - `read(path: str) -> list[dict]` (classmethod).
- `verify(path: str) -> VerifyResult` — total with respect to file *content*: no bytes inside the file
  make it raise. It can still raise on the file *handle* — `open(path, "rb")` is unguarded, so a
  directory or an unreadable file raises `IsADirectoryError` / `PermissionError`, which `cli.main()`
  does not catch. Per line it requires UTF-8 decodability,
  JSON parseability, dict-ness, `canonical_json(ev) == line` byte-for-byte, `seq == expected`,
  `prev_hash == previous hash`, and `event_hash(ev) == ev["hash"]`. A missing file yields `ok=False`.
- `@dataclass VerifyResult(ok: bool, count: int, first_bad_seq: int | None, errors: list[str])`.
- `GENESIS_PREV_HASH = "0" * 64`.

### `aileron.signing`

- `generate_keypair(dir_path: str) -> tuple[str, str]` — writes `aileron_ed25519.key` (`0o600`) and
  `aileron_ed25519.pub` (`0o644`), both with `O_NOFOLLOW`.
- `sign_checkpoint(log_path: str, key_path: str) -> dict` — raises `ValueError` on a broken chain
  ("refusing to sign broken chain: …") or an empty log ("refusing to sign an empty log: nothing to
  attest"). Appends one canonical line to `<log_path>.checkpoints.jsonl`.
- `verify_checkpoint(log_path: str, key_path: str) -> bool`.
- `check_against_checkpoints(log_path: str) -> list[str]` — 0.1.3; **unauthenticated** cross-check
  that distinguishes "appears truncated" from "appears rewritten". Signatures are not checked here.
- Constants: `PRIVATE_KEY_NAME`, `PUBLIC_KEY_NAME`.

### `aileron.policy`

- `@dataclass Rule(id, title, severity, match: dict, action)`.
- `@dataclass Decision(action: str, rule_ids: list[str])`.
- `matches(rule: Rule, event: dict) -> bool`.
- `decide(event: dict, rules: list[Rule]) -> Decision` — rules are evaluated in list order; the first
  matching `block` returns immediately with that single id; otherwise all matching `alert` ids are
  collected; otherwise `Decision("allow", [])`. A matching `allow` rule has no effect.
- `load_rules(path: str | Path) -> list[Rule]` — a single file, or a directory scanned for
  `.yml`/`.yaml` **sorted by name** (this sort is what makes "first block wins" deterministic).
  Raises `ValueError` naming the offending file.
- Constants: `SEVERITY_ORDER = ["low","medium","high","critical"]`, `ACTIONS = ("allow","alert","block")`.

### `aileron.detect`

- `class Baseline(path: str | None = None)`
  - `flag(event: dict) -> list[str]` — pure, no mutation; call before `observe`. Emits
    `first_seen_tool:<name>`, `rate_spike:<tool>`, `novel_sequence:<a>-><b>`.
  - `observe(event: dict) -> None`, `save() -> None`, `load() -> None`.
  - Only `tool_call` events with a non-empty string tool name are considered.
- Constants: `RATE_WINDOW_SECONDS = 60.0`, `RATE_SPIKE_FACTOR = 3.0`, `RATE_MIN_OBSERVATIONS = 5`,
  `MAX_TIMESTAMPS_PER_TOOL = 1000`.

### `aileron.sdk`

- `track(tool_name: str | None = None, log: ChainLog | None = None, rules: list | None = None, baseline: Any | None = None) -> Callable[[F], F]`
  — on a `block` decision, journals the attempt with `status="blocked"` and raises `PolicyBlocked`
  **without invoking the wrapped function**.
- `class PolicyBlocked(RuntimeError)` with `.rule_id`.
- `class AgentSession(name, framework, log=None)` — context manager emitting `agent_start` /
  `agent_end`; identity flows through a `ContextVar`.
- `track_agent(name: str, framework: str, log: ChainLog | None = None) -> AgentSession`.
- `default_log() -> ChainLog` — resolves `AILERON_LOG` (default `./aileron.chain.jsonl`) **once**
  into a process-global singleton; later env changes have no effect.

### `aileron.proxy`

- `run_proxy(child_argv: list[str], log: Any, rules: list | None = None) -> int` — returns the
  child's exit code. `log` is duck-typed: anything with `append`, plus an optional `capture_content`
  attribute read via `getattr`.
- Constants: `MAX_MESSAGE_BYTES = 64 * 1024 * 1024`, `MAX_PENDING = 4096`, `CHILD_EXIT_TIMEOUT = 5.0`.
- Wire behaviour: both newline-delimited and `Content-Length`-framed JSON-RPC 2.0; a block returns
  `-32000 blocked by aileron rule <id>`; unparseable input returns `-32700`; unavailable recording
  returns `-32000 aileron: recording unavailable, call refused`.

### `aileron.otel` and `aileron.report`

- `to_otel_spans(events: list[dict]) -> list[dict]`, `to_otlp_spans(events: list[dict]) -> list[dict]`,
  `export_json(events: list[dict], out_path: str) -> None`.
- `render_html(events: list[dict], verify_result: Any, out_path: str, title: str = "Aileron Incident Report") -> None`.

## CLI

`prog = "aileron"`; a subcommand is required. Defaults: `DEFAULT_LOG = "aileron.chain.jsonl"`,
`DEFAULT_KEY = "aileron_ed25519.key"`, `DEFAULT_PUB = "aileron_ed25519.pub"`.

| Command | Positionals | Flags |
|---|---|---|
| `init` | — | `--dir` (default `.`) |
| `verify` | `log` | `--skip-checkpoint-check` |
| `sign-checkpoint` | `log` | `--key` |
| `verify-checkpoint` | `log` | `--key` |
| `report` | `log` | `-o/--out` (**required**), `--title`, `--skip-checkpoint-check` |
| `export` | `log` | `-o/--out` (**required**) |
| `detect` | `log` | `--state`, `--save` |
| `rules test` | `rules_path`, `log` | — |
| `proxy` | `cmd` (`nargs=REMAINDER`) | `--log` (**required**), `--rules`, `--capture-content` |
| `demo` | — | `--dir` (default `.`) |

Exit codes as implemented:

- `verify` — `0` OK; `2` on a chain break **and** `2` on a checkpoint contradiction; `2` also for a
  missing log file, where the message is the misleading `TAMPERED at seq None` (logged as debt).
- `report` — `0` if verification passed, `2` otherwise. The HTML is written either way, and a
  checkpoint contradiction forces the badge away from `VERIFIED`.
- `verify-checkpoint` — `0` valid; `1` invalid; `1` when no key file can be found.
- `detect` — `0`; `1` if `--save` is passed without `--state`.
- `proxy` — the child's exit code; `1` if no command follows `--`. A leading literal `--` is stripped.
- `demo` — `0` if the resulting chain verifies, else `2`. `export`, `init`, `rules test` — `0`.
- `main()` catches `FileNotFoundError`, `ValueError`, `KeyError`, `ImportError` → message on stderr,
  return `1`.

`verify-checkpoint` prints the resolved absolute key path and a `sha256:<16 hex>` fingerprint, and
warns on stderr when the key was auto-resolved from the log's own directory — the trust anchor is
disclosed rather than assumed.

## Data Models

### Event (15 keys, all required by `validate`)

| Field | Type | Notes |
|---|---|---|
| `id` | str | uuid4 hex, 32 lowercase hex chars |
| `ts` | str | RFC3339 UTC, millisecond precision, `Z` suffix |
| `seq` | int | ≥ 0; genesis event in a journal is `1` |
| `session_id` | str | groups events from one agent run |
| `agent` | dict | `{name, framework, version}` |
| `type` | str | one of `EVENT_TYPES` |
| `tool` | dict \| None | `{name, arguments, arguments_digest}`; `arguments` is `None` on disk unless capture is on |
| `result` | any \| None | `None` on disk unless capture is on |
| `result_digest` | str \| None | SHA-256 hex |
| `status` | str | `ok` \| `error` \| `blocked` |
| `latency_ms` | number \| None | |
| `policy` | dict \| None | `{rule_id, action}` |
| `meta` | dict | free-form; used for `notification`, `error`, and proxy diagnostics |
| `prev_hash` | str | 64 hex; genesis is 64 zeros |
| `hash` | str | 64 hex; `sha256(canonical(event minus hash))` |

`llm_call` and `policy_decision` are declared in `EVENT_TYPES` (and `llm_call` is mapped in
`otel._OPERATION`) but no module currently emits them.

### Checkpoint — `<log>.checkpoints.jsonl`

Fields: `ts`, `log_path`, `index` (1-based), `prev_checkpoint_hash`, `count`, `tip_hash`,
`signature` (base64 Ed25519), `pubkey_path`. The signature covers the canonical JSON of the record
**minus `signature` and `pubkey_path`**, i.e. `ts`, `log_path`, `index`, `prev_checkpoint_hash`,
`count`, `tip_hash`. `prev_checkpoint_hash` is the SHA-256 of the previous checkpoint's signed
payload, genesis 64 zeros — checkpoints form their own chain, so reordering or deleting an
intermediate checkpoint is detectable. Deleting the *newest* checkpoint remains undetectable; it is
tail truncation.

### Policy rule (YAML)

Required: `id` (non-empty str), `match` (non-empty mapping), `action` (`allow`|`alert`|`block`).
Optional: `severity` (default `medium`, must be in `SEVERITY_ORDER`), `title` (default `""`).
Unknown top-level keys are silently ignored.

Clause forms, all AND-ed within a rule:

1. `dotted.key: value` — exact equality after dotted traversal.
2. `dotted.key_contains: [str, ...]` — case-insensitive substring, any-of. Haystack is the value
   itself if it is a string, else its `canonical_json`.
3. `dotted.key_regex: pattern` — `re.search`; an invalid pattern simply fails to match.
4. `severity_gte: <level>` — compares a **top-level** `event["severity"]`, which no built-in producer
   sets, so this matcher cannot fire on events this package produces.

A missing path segment, or a non-dict in the middle of a path, means the clause does not match.

### Baseline state (JSON)

`{"version": 1, "tool_counts": {session: {tool: count}}, "tool_ts": {tool: [epoch, ...]},
"seen_tools": [...], "last_tool": {session: tool}, "transitions": ["a->b", ...]}`.
`tool_ts` is capped at 1,000 entries per tool. `load` is defensive: missing, corrupt, or wrongly
typed state leaves the baseline empty rather than raising.
